# Model card

## Intended use

Offline **demo** of URL and email phishing scoring. Not a replacement for a browser Safe Browsing feed, email gateway, or SOC tooling.

## Training data

Synthetic URLs and emails generated by `scripts/prepare_data.py` (14k URLs, 10k emails). Labels are assigned by construction. There is **no** public phishing corpus in this repository.

Because positives and negatives are generated from distinct templates, hold-out ROC-AUC on the synthetic set is near 1.0. Treat that as a smoke test of the pipeline, not real-world detection performance.

## Models

| Task | Pipeline | Hold-out (synthetic) |
| --- | --- | --- |
| URL | lexical/structural features → StandardScaler → Random Forest | ROC-AUC 1.00 (synthetic) |
| Email | word+char TF-IDF + numeric heuristics → SGDClassifier (`log_loss`) | ROC-AUC 1.00 (synthetic) |

Thresholds: `src/phishguard/settings.py` (`Safe` < 0.32, `Suspicious` < 0.72, else `Phishing`).

## Failure modes

- Obfuscated or brand-new phishing kits will not match synthetic templates.
- Very short URLs/emails return `Uncertain` rather than a forced class.
- joblib pickles are trusted artifacts from `make train` only.

## Fixture models

`tests/fixtures/models/` are tiny forests/pipelines for CI. They are **not** the demo models. Run `make train` for the dashboard metrics.
